# Kế hoạch triển khai FR-SRCH-003 và FR-SRCH-004

## Mục tiêu

Hoàn thiện sort cho list/search và UI theo FR-SRCH-003; kiểm tra regression pagination theo FR-SRCH-004 mà không thay đổi hợp đồng sẵn có.

## Hiện trạng đã khảo sát

- `GetRecipesQueryHandler` đã có whitelist sort cho luồng list.
- `RecipeRepository.SearchAsync` hiện xếp hạng FTS, chưa nhận tiêu chí sort.
- Endpoint search đã nhận sort params qua `RecipeSearchRequest`; trang `/search` hiện chưa cung cấp control sort.
- Pagination flat, mặc định 1/12, giới hạn page size 50; handler dùng `CountAsync`, `Skip/Take`, UI có nút trang trước/sau.
- `CONFLICT-003` chốt explicit params; `CONFLICT-012` chốt flat response shape.
